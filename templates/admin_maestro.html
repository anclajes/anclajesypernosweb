Guía y recomendaciones

¿Qué hace esta sección hoy?

  • Lee la hoja MAESTROV2 de tu Excel Maestro.
  • Usa la columna NUEVO CODIGO como llave (es el mismo código que sku en Anclajes e ImportBolts).
  • Si ese código existe en Anclajes, ImportBolts, o en ambos, actualiza el Peso Nominal (Kg) ahí donde el peso sea distinto.
  • Cada cambio real queda en el historial (código, inventario, peso anterior/nuevo, fecha, usuario) para que puedas auditar qué se tocó.
  • Un peso vacío o en 0 en el Maestro no borra el peso que ya tenías guardado (se ignora esa fila).
  • No crea productos nuevos: si un código del Maestro no existe todavía en ningún inventario, solo se reporta como "no encontrado" para que lo revises tú.

Cómo te recomiendo usarlo bien

  • Mantén NUEVO CODIGO como el código único y definitivo — evita reutilizar CODIGO ORIGEN/CODIGO1.1 para nada nuevo, son solo referencia histórica.
  • Súbelo después de cada actualización real del Excel Maestro (por ejemplo, cuando el área de costos/ingeniería cierre una revisión de pesos), no en cada venta o movimiento diario.
  • Revisa siempre el resumen de "códigos no encontrados" después de subirlo: normalmente son productos que faltan crear, o un código mal tipeado.
  • Antes de una subida grande, puedes descargar el respaldo JSON completo del sistema (en la Zona de Administración) por si necesitas revertir algo.

Qué más se le podría agregar más adelante

  • Sincronizar también Descripción, Calidad y Familia (hoy solo se avisan las diferencias, no se aplican) — con el mismo tipo de auditoría por campo.
  • Crear automáticamente (con tu confirmación) los códigos del Maestro que no existan todavía en ningún inventario.
  • Exportar un Excel comparativo: Maestro + estado actual en Anclajes/ImportBolts + diferencias, ordenado por código, listo para revisión o para reemplazar al Excel Maestro.
  • Usar el Código de Barras del Maestro para habilitar lectura con lector de código de barras en el picking o en auditoría física.
  • Guardar las bandas de precio (Mínimo/Medio/Máximo) del Maestro como referencia al momento de cotizar, sin que reemplacen el precio real que ya manejas.
  • Un modo "vista previa" que muestre los cambios detectados antes de aplicarlos, para confirmar antes de guardar (como ya existe en Borrar Todo / Restaurar).
