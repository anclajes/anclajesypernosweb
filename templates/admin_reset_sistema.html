Restaurar un respaldo / Backups automáticos

¿Ya descargaste (o el sistema ya generó) un respaldo JSON antes? Desde aquí lo puedes volver a subir para traer de vuelta todos los datos, tal cual estaban.

Restaurar desde un archivo de respaldo

El sistema también puede generar estos respaldos solo, cada cierto tiempo, sin que nadie tenga que entrar aquí — se guardan directamente en tu almacenamiento S3, en la carpeta backups_automaticos/. Para activarlo, hay que configurar un Cron Job (en Render o en un servicio externo gratuito) que llame a esta URL periódicamente:

/sistema/backup_automatico?token=TU_TOKEN_SECRETO

(el token se configura una vez como variable de entorno BACKUP_CRON_TOKEN — pregúntame si quieres que te ayude a dejarlo listo)
