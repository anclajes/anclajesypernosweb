Restaurar desde un Respaldo

Sube el archivo JSON que descargaste (o que el sistema generó automáticamente) y se van a recrear todos los datos que traiga, tal cual estaban.

  • Esto solo funciona sobre un sistema recién limpiado (después de "Borrar Todo"), no encima de datos reales ya cargados — si ya hay productos, clientes u órdenes, la restauración se rechaza por seguridad.
  • Ninguna fila se pisa ni se duplica: si algo ya existe con el mismo ID, simplemente se salta.
  • Al final se te mostrará cuántas filas se restauraron por cada tabla.
